# 🕊️ طوقی | Toghi — بازار لوکس کبوتر، پرندگان و حیوانات خانگی

سایت «طوقی» یک بازار آنلاین شبیه دیوار، مخصوص خرید و فروش کبوترهای تزئینی (پا‌پر و گردن‌فر)، طوطی‌های سخنگو، قناری، مرغ عشق و حیوانات خانگی است — با طراحی لوکس سبز زمردی و طلایی، کاملاً فارسی و راست‌چین.

## ✨ امکانات

- **صفحه اصلی لاکچری** با عکس کبوتر یعقوبی پا‌پر و گردن‌فر، جستجوی زنده، آمار و گالری آگهی‌های ویژه طلایی
- **بازار آگهی‌ها** با فیلتر دسته‌بندی، شهر، قیمت، جستجو و مرتب‌سازی (جدیدترین، ارزان‌ترین، پربازدیدترین)
- **صفحه جزئیات آگهی** با گالری عکس، مشخصات نژاد/سن/جنسیت، نمایش شماره فروشنده، پیام به فروشنده و آگهی‌های مشابه
- **ثبت آگهی رایگان** با آپلود تا ۶ عکس، آگهی ویژه طلایی و فروش فوری
- **نشان‌کردن (علاقه‌مندی‌ها)** با قلب روی هر آگهی
- **پنل مدیریت و ویرایش زنده** در آدرس `/admin` (رمز پیش‌فرض: `toghi123`)
  - ویرایش زنده‌ی **همه‌ی متن‌های سایت** (تیترها، درباره، آمار، فوتر و...)
  - تغییر **عکس اصلی سایت و همه عکس‌ها** با آپلود یا لینک
  - مدیریت کامل آگهی‌ها (ویرایش، حذف، ویژه‌کردن، مخفی‌کردن)
  - ساخت و حذف دسته‌بندی، مشاهده پیام‌های خریداران و آمار بازدید

## 🚀 اجرا و توسعه

```bash
npm install
# ساخت فایل .env با آدرس دیتابیس PostgreSQL
echo 'DATABASE_URL=postgresql://user:pass@host:5432/dbname' > .env
npx drizzle-kit push   # ساخت جدول‌ها (یا به‌صورت خودکار هنگام اولین اجرا ساخته می‌شوند)
npm run dev            # توسعه
npm run build && npm start  # انتشار
```

## ☁️ انتشار روی GitHub و Cloudflare

1. این پروژه را در یک ریپوزی GitHub آپلود کنید (`git init` → `git add .` → `git commit` → `git push`).
2. برای اجرای کامل سایت (دیتابیس PostgreSQL + آپلود عکس + API)، بهترین گزینه‌ها:
   - **Cloudflare Pages + دیتابیس ابری:** ریپو را در Cloudflare Pages ایمپورت کنید و در بخش Environment Variables مقدار `DATABASE_URL` را آدرس یک PostgreSQL ابری (مثل Neon یا Supabase) قرار دهید.
   - یا یک سرور Node ارزان (مثل Railway/Render/VPS) که مستقیم به گیت‌هاب وصل می‌شود و با هر Push به‌صورت خودکار آپدیت می‌شود.
3. توجه: آپلود عکس در پوشه `public/uploads` ذخیره می‌شود؛ روی هاست‌های بدون دیسک دائمی از «لینک عکس» در پنل مدیریت استفاده کنید (پشتیبانی کامل دارد).

## 👤 حساب کاربری و احراز هویت

- هر کاربر با **شماره موبایل + کد تایید پیامکی (OTP)** وارد می‌شود: `/login`
- کاربر جدید در همان لحظه با **نام و کد ملی** ثبت‌نام می‌شود؛ کد ملی با الگوریتم رسمی رقم کنترلی اعتبارسنجی می‌شود و نشان «احراز هویت‌شده» می‌گیرد.
- برای ارسال **پیامک واقعی** کافی است در فایل `.env` سرور مقدار `KAVENEGAR_API_KEY` (کلید کاوه‌نگار) را قرار دهید؛ بدون آن، کد برای تست روی صفحه نمایش داده می‌شود.
- هر کاربر **پنل شخصی** دارد: `/account` — ویرایش پروفایل و کد ملی، مشاهده و مدیریت آگهی‌های خودش (فروخته شد، مخفی، حذف)، آمار بازدید و نشان‌شده‌ها.
- ثبت آگهی فقط بعد از ورود امکان‌پذیر است و آگهی به حساب کاربر وصل می‌شود.
- منوی اصلی سایت در **پایین صفحه** (مثل اپ دیوار) است و دکمه طلایی «ثبت آگهی» در وسط آن قرار دارد.

## ❓ پاسخ دو سؤال مهم

**۱) آیا روی سرور هم ویرایش زنده داریم؟** بله. همه متن‌ها، عکس‌ها، آگهی‌ها و تنظیمات در دیتابیس ذخیره می‌شوند؛ پنل `/admin` روی سرور دقیقاً مثل محیط تست، بدون آپلود مجدد فایل، تغییرات را همان لحظه در سایت اعمال می‌کند. فقط کافی است `DATABASE_URL` روی سرور تنظیم شده باشد.

**۲) نصب مستقیم روی کلودفلر یا اول گیت‌هاب؟** مسیر استاندارد کلودفلر این است: فایل‌ها را در یک ریپوی **گیت‌هاب** بگذارید و در Cloudflare Pages همان ریپو را Import کنید تا با هر Push سایت خودکار به‌روز شود (آپلود مستقیم با Wrangler هم ممکن است). اما توجه فنی مهم: این نسخه کامل طوقی از PostgreSQL و ذخیره فایل روی دیسک و Node.js استفاده می‌کند که روی محیط Workers کلودفلر مستقیم اجرا نمی‌شود؛ پس برای اجرای کامل (دیتابیس + آپلود عکس + پیامک)، پیشنهاد ما اتصال همان ریپوی گیت‌هاب به یک هاست Node مثل Railway یا Render یا یک VPS است. اگر اصرار به ماندن کامل روی کلودفلر باشد، باید دیتابیس به Cloudflare D1 و آپلود عکس به R2 منتقل شود که نیازمند نسخه اختصاصی کلودفلر است.
